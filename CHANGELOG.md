# Changelog

## 2.1.0

- Public GitHub distribution with Marketplace / HACS installation and release updates.
- Ukrainian and English interfaces and documentation.
- Removed the last-received timestamp entity; receipt time remains in diagnostics.
- Improved Ukrainian entity names and added branded artwork.
- Synthetic test fixtures without installation-specific addresses or captures.

## 2.0.0

- Graphical IP-based setup and reconfiguration.
- Automatic channel B configuration and Wi-Fi module restart with recovery snapshots.
- Extended W0003 decoding: temperature/humidity extrema, battery flags, radio status and protocol diagnostics.
- Local pressure remains optional and unavailable when the station does not provide it.
