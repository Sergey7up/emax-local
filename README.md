EMAX Local отримує вимірювання безпосередньо зі станції через локальну мережу. Введіть IP-адресу у графічному майстрі: інтеграція визначить сумісний Wi-Fi-модуль, підготує TCP-приймач, налаштує канал B та перезапустить модуль.

Канал A зберігає попередні налаштування, тож застосунок виробника може працювати паралельно. Обліковий запис EMAX та хмарний API для отримання локальних вимірювань не потрібні.

## Що ви отримаєте

| Дані | У Home Assistant |
|---|---|
| Температура та вологість станції й трьох зовнішніх каналів | 8 сенсорів із довгостроковою статистикою |
| Мінімум і максимум, які передає станція | Атрибути `station_min` / `station_max` кожного сенсора |
| Попередження про розряд | 4 двійкові сенсори батарей |
| Приймання зовнішніх датчиків | 3 діагностичні сенсори зв'язку |
| Стан налаштування | Один діагностичний сенсор |
| Перезапуск Wi-Fi-модуля | Кнопка на сторінці пристрою |
| Час станції, час отримання, сирі поля й стан протоколу | Завантажувана діагностика |

Після 180 секунд без коректного пакета вимірювання стають недоступними. Відсутні дані не перетворюються на нулі. Утримувані станцією старі значення зовнішнього датчика не видаються за нові.

## Сумісність

Перевірено формат **W0003 v01**, 50-байтний пакет вимірювань, модуль **HF-LPT230**, прошивка **4.12.17**. Home Assistant **2026.11 або новіший**, доступ TCP від станції до HA та UDP 48899 від HA до станції.

Назва EMAX не гарантує однаковий протокол у всіх моделях. Невідомі версії пакетів відхиляються. Декодери споріднених EM3371 / EM3378D / FanJu використано як джерела опису формату; їхня сумісність із цією інтеграцією не заявляється. [Детальна карта протоколу →](docs/protocol.md)

## Установлення через Marketplace / HACS

1. Відкрийте **Налаштування → Marketplace** (або HACS у попередніх інсталяціях). Прочитайте початкове попередження та підключіть GitHub, якщо магазин цього потребує.
2. Додайте власний репозиторій: **`Sergey7up/emax-local`**, категорія **Integration**.
3. Завантажте **EMAX Local** та перезапустіть Home Assistant.
4. Відкрийте **Налаштування → Пристрої та служби → Додати інтеграцію → EMAX Local**.
5. Укажіть IPv4-адресу станції, перевірте знайдені параметри та підтвердьте налаштування.

Інтеграція запустить приймач перед зміною каналу B. Після автоматичного перезапуску Wi-Fi-модуля стан має змінитися на **«Вимірювання надходять»**. Виймати батарейки для звичайного налаштування сумісного модуля не потрібно. Команда перезапускає Wi-Fi-модуль, а не основний контролер дисплея.

Якщо канал B вже використовується іншим приймачем, майстер вимагає окремого підтвердження заміни. Налаштування для відновлення зберігаються локально в `/config/emax_local_backups/`.

### Оновлення

Нові випуски з цього GitHub-репозиторію доступні через той самий магазин. Установіть оновлення та перезапустіть HA. Домен `emax_local`, MAC-ідентичність пристрою й унікальні ідентифікатори вимірювань зберігаються при оновленні. Для старої ручної інсталяції встановіть пакет із магазину поверх наявного й збережіть поточну інтеграцію.

## Про батарейки й атмосферний тиск

**Батареї показують попередження про розряд, а не відсотки.** Поле живлення інтерпретується як бітова маска. Значення `1`, `2`, `4` — позиції бітів, а не три рівні заряду. Відповідність зовнішніх каналів спирається на декодер EM3371 та зіставлення W0003 із полями хмарного API; окремого контрольного досліду з кожною батареєю ще немає. Для датчика без актуального радіосигналу стан батареї недоступний.

**Тиск — лише якщо його передає станція.** Необов'язковий локальний сенсор вимкнений за замовчуванням. Перевірена W0003 передає `FFFF`, тобто тиск відсутній. Хмарний прогноз, вітер, опади й хмарний тиск не підміняють локальні вимірювання.

## Діагностика та підтримка

Перевірте стан підключення на сторінці пристрою. За потреби завантажте діагностику інтеграції та перегляньте журнал HA. Перед публікацією будь-якого журналу перевірте його на приватні дані; файли відновлення містять мережеві параметри.

У [зверненні](https://github.com/Sergey7up/emax-local/issues) зазначте модель станції, версії HA та інтеграції, очікувану й фактичну поведінку. Для зміни IP використовуйте **Переналаштувати** в меню інтеграції.

## Розробка

```sh
python -m unittest discover -s tests -v
```

Тести використовують синтетичні пакети, локальні TCP/UDP-сокети та ізольовану модель керування. Реальний цикл налаштування й відновлення передачі окремо перевірено на Home Assistant. Зображення бренду створено за допомогою AI; проєкт не пов'язаний із виробником EMAX.
